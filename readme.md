
# ECサイト Webアプリケーション（ハンズオン制作）

Web制作コーディング基礎講座のハンズオンにて作成した、Node.js / Express / SQLite3 を活用した簡易ECサイト（Webショッピングモール）アプリケーションです。  
ユーザーの新規登録・ログイン機能から、商品一覧・詳細閲覧、ショッピングカートの管理、購入手続き、および管理者による商品管理（CRUD操作）までの一連の機能を実装しています。

---

## 📌 主な機能

### 1. 認証機能（ユーザー／管理者）
* **ユーザー登録**: 英大文字・小文字・数字・記号を含む12文字以上のパスワードバリデーションを実装。
* **一般ログイン / 管理者ログイン**: ロール（一般ユーザー／管理者）に応じた権限分離。
* **セッション管理**: `express-session` を用いたログイン状態およびユーザー情報の保持。

### 2. 一般ユーザー向け機能
* **商品一覧表示**: データベースから取得した商品情報の一覧表示。
* **商品詳細表示**: 個別商品の詳細情報閲覧。
* **ショッピングカート機能**:
  * 商品のカート追加（重複追加時は数量を加算更新）
  * カート内商品の数量変更・削除
  * 合計金額の自動計算
* **購入手続き**: カート内商品の一括購入と処理完了後のカートクリア。

### 3. 管理者向け機能（商品管理 CRUD）
* **商品追加**: 新規商品の登録（商品名、価格、説明、画像URL）。
* **商品編集・更新**: 既存商品情報の変更。
* **商品削除**: 登録済み商品の削除。

## 🗄 データベース構造（SQLite3）

主に以下のテーブル構成でデータを保持・操作しています。

* **`users` テーブル**: ユーザー情報（ID, ユーザー名, パスワード, ロール権限）
* **`products` テーブル**: 商品情報（ID, 商品名, 価格, 説明, 画像URL）
* **`cart` テーブル**: カート情報（ID, ユーザーID, 商品ID, 数量）

## 🚀 動作方法（ローカル環境）

### 1. リポジトリのクローン
```bash
git clone https://github.com/your-username/your-repository-name.git
cd your-repository-name
```

### 2. パッケージのインストール
```bash
npm install
```

### 3. データベースの初期化

以下のコマンドを実行し、データベースファイル (`database.sqlite`) の作成、テーブル構築、および初期サンプルデータの投入を行います。

```bash
npm run init-db
```

### 4. アプリケーションの起動
```bash
npm start
```
* 起動後、ブラウザで `http://localhost:3000` にアクセスしてください。

## 💡 工夫した点・学習したポイント

* **安全なデータ操作（プレースホルダーの利用）**: 
  SQLite3のクエリ実行時には `?` によるバインド変数（プレースホルダー）を使用し、SQLインジェクション対策を行いました。
* **バリデーションの実装**: 
  ユーザー登録時に正規表現を用いて複雑なパスワード要件（12文字以上、大文字・小文字・数字・記号の組み合わせ）のチェックを行い、セキュリティ面を意識しました。
* **セッション・リレーションの活用**: 
  ログイン中の `userId` をセッションで保持し、`cart` テーブルと `products` テーブルを `JOIN` することでユーザーごとに独立したカート管理を実現しました。
* **商品内容・画像の変更**
  講座の初期データから商品構成・画像・説明の変更を実施しました。
* **データベース構造定義ファイル (`schema.sql`) の追加**
  データベース（`database.sqlite`）のテーブル構築（`users`, `products`, `cart`）を定義・管理するために追加しました。
* **初期データ投入スクリプト (`seeds.sql`) の追加**
  テスト用のユーザーデータや初期商品データをスムーズに投入・再構築できるように追加しました。
